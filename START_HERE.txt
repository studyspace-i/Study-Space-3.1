STUDY SPACE APP v2.5.1 — APK banana (Android Studio ki zaroorat nahi)
1. GitHub par repository banao. Is zip ka sab kuch upload karo (".github" folder bhi).
2. Repository -> Actions tab -> "Build Android APK" -> wait ~10 minute.
3. Artifacts / Releases se StudySpace.apk download karke install karo (purane app ke upar install ho jata hai).
v2.5.1: Permissions ab ek-ek karke maangta hai (Notifications, Camera, Location). App ka apna camera + face detection.
